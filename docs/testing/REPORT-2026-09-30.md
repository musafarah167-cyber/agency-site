## Findings for the other sessions
1. **(Design/front end, low)** Reduced-motion pause runs only once at page load (`site/script.js` last lines). If someone turns reduce-motion on while the page is open, it is not picked up. Fix: also listen for the media query changing.
2. **(Front end, low)** After a failed form submit the error appears but focus stays on the button and no field is marked `aria-invalid`. Keyboard/screen reader users may not notice. Suggest moving focus to the first empty field.
3. **(Design, low)** Header logo link is 31px tall on phones (project rule says 44px). Inline phone link in the contact paragraph is 19px; inline text links are normally exempt, so optional.
4. **(Front end, low)** Phone field has `autocomplete="tel"` but accepts an email too.
5. **(Front end, Phase 3)** Missing before launch: `noindex` on staging, robots.txt, sitemap.xml, canonical, `og:url`, `og:image` (share picture), `apple-touch-icon`, LocalBusiness data. Also no privacy/terms pages yet, and no "Farah Musa trading as Clear Signs" anywhere on the site (decision 2026-09-29 says address stays off; revisit if gov.uk requires).
