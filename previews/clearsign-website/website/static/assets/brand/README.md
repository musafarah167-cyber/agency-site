# ClearSign identity — charcoal, warm white and amber

17 November 2026. Palette selected by Khalid; stronger amber hierarchy and the original large C animation retained at his request. Website publication remains separate.

- `wordmark-light.svg`: charcoal C/name with an amber detached square, for light backgrounds.
- `wordmark-dark.svg`: ivory C/name with an amber detached square, for dark backgrounds.
- `wordmark-mono.svg` and `wordmark-white.svg`: single-colour variants.
- `signature-light.svg` and `signature-dark.svg`: primary versions with the Solutions descriptor.
- `signature-mono.svg` and `signature-white.svg`: single-colour signatures.
- `symbol-dark.svg` and `symbol-white.svg`: primary/reversed symbols with an amber square.
- `symbol-mono.svg` and `symbol-white-mono.svg`: one-colour production symbols.

Use the supplied geometry without distortion. The full visual usage guide is `brand.html` two folders above in the generated website. Archivo is embedded in the wordmarks under the SIL Open Font License in `FONT-LICENSE.txt`. Printed and embroidered samples have not been checked; specialist production may need outlined lettering.
